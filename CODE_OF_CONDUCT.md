# Code of Conduct

## Expected behavior

Treat contributors respectfully. Critique ideas and code rather than people.
Welcome good-faith questions, give actionable feedback, and respect differences
in background, experience, and communication style.

Harassment, threats, discrimination, sexualized conduct, doxxing, impersonation,
and persistent unwanted contact are not acceptable. Do not publish personal
information or private discussions without permission. Do not spam issues or
pressure reviewers for merges, privileges, or rewards.

## Scope

These expectations apply in repository issues, pull requests, reviews, and other
project-managed collaboration spaces, including when representing the project.

## Reporting and enforcement

Ask a repository administrator for a private reporting channel without posting
sensitive details publicly. If a complaint concerns one administrator, request
another uninvolved administrator where available. A dedicated confidential
contact has not yet been published; do not assume public issues are private.

Administrators should review reports confidentially on a need-to-know basis,
consider context and safety, and explain decisions to the affected parties when
appropriate. Responses can include a warning, removal of content, temporary
restrictions, or removal of access. Retaliation against a good-faith reporter is
not acceptable. Reconsideration may be requested privately from an uninvolved
administrator where available; an independent appeal panel is not currently
established.
